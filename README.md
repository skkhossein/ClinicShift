# ClinicShift

سامانه مدیریت درخواست و پذیرش شیفت.

## وضعیت پیاده‌سازی

این مخزن در مرحله ایجاد زیرساخت اولیه است. قابلیت‌های محصول، احراز هویت، مدیریت ظرفیت، گردش‌کار تأیید درخواست و اعلان‌رسانی باید پیش از استفاده عملیاتی تکمیل و آزمون شوند.

## فناوری هدف

- Cloudflare Workers برای API و اجرای برنامه
- Cloudflare D1 برای داده‌ها
- رابط وب فارسی و راست‌چین
- Wrangler برای توسعه و استقرار
- GitHub Actions برای استقرار خودکار

## توسعه محلی

نیازمند Node.js 20 یا جدیدتر است. پس از افزودن فایل‌های برنامه و نصب وابستگی‌ها:

```bash
npm install
npm run dev
```

## سلامت سرویس

مسیر پیشنهادی بررسی سلامت سرویس:

```
GET /api/health
```

## امنیت

هیچ‌گاه API Token، رمز عبور یا اطلاعات محرمانه را در مخزن ثبت نکنید. مقادیر محرمانه استقرار باید در GitHub Actions Secrets و تنظیمات امن Cloudflare نگهداری شوند.

## استقرار

فایل پیکربندی Wrangler، migrationهای D1 و workflow استقرار پس از آماده‌سازی کد برنامه اضافه خواهند شد. تا آن زمان این مخزن آماده استقرار عملیاتی نیست.
